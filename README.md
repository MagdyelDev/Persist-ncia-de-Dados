Critérios de Avaliação

A — Atendido

Integra Node.js e SQLite. 

Cria banco de dados e tabela. 

Executa gravação e consulta de dados. 

Compreende o fluxo servidor → banco de dados. 

Explica com clareza a necessidade da persistência. 

PA — Parcialmente Atendido

Realiza a integração com apoio. 

Apresenta dificuldades pontuais na manipulação do banco de dados e SQL. 

Necessita de auxílio para explicar o conceito de persistência. 

NA — Não Atendido

Não realiza a integração entre Node.js e SQLite. 

Não executa operações básicas de SQL. 

Não compreende o papel do banco de dados na aplicação. 

Não diferencia memória RAM de persistência de dados.
